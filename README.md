# ToDo лист API

Учебный API для просмотра задач и их классификации по матрице Эйзенхауэра:

- Q1: важные и срочные.
- Q2: важные и несрочные.
- Q3: неважные и срочные.
- Q4: неважные и несрочные.

Временное хранилище содержит четыре задачи. Данные хранятся в памяти приложения.

## Технологии

Python 3.10+, FastAPI, Pydantic, Uvicorn.

## Запуск

В терминале из папки проекта создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его в Git Bash на Windows:

```bash
source venv/Scripts/activate
```

Либо в PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Установите зависимости и запустите приложение:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

API: http://127.0.0.1:8000/. Интерактивная документация: http://127.0.0.1:8000/docs.
Остановка сервера: `Ctrl+C`.

## Эндпоинты

| Метод | URL | Назначение |
| --- | --- | --- |
| GET | `/` | Приветствие и информация об API |
| GET | `/tasks` | Все задачи и их количество |
| GET | `/tasks/quadrant/Q1` | Фильтрация по квадранту Q1, Q2, Q3 или Q4 |
| GET | `/tasks/stats` | Общее количество задач, статистика по квадрантам и выполнению |
| GET | `/tasks/status/completed` | Выполненные задачи; `pending` возвращает невыполненные |
| GET | `/tasks/search?q=проект` | Поиск в названии или описании, минимум два символа |
| GET | `/tasks/1` | Полная информация о задаче с указанным ID |

Неверный квадрант и слишком короткий поисковый запрос возвращают 400.
Несуществующая задача, неизвестный статус и отсутствие результатов поиска возвращают 404.
